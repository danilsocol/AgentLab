# AgentLab

Учебный локальный ассистент на Qwen 2.5 3B или Llama 3.2 3B.

- **`assistant.py` — ДЗ 1:** погода, курсы валют, статьи Wikipedia и книги.
- **`assistant_with_memory.py` — ДЗ 1 + ДЗ 2:** те же инструменты, LangChain
  и долговременная память фактов пользователя.

Модель выбирает функции через текст `$function$имя("аргумент")$function$`.
Программа разбирает вызов, запрашивает реальный API и передаёт результат модели.
Ключи API и регистрация не нужны.

## Установка

Python 3.10+. Команды PowerShell выполняются из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Поместите хотя бы одну GGUF-модель в `models/`:

- `qwen2.5-3b-instruct-q4_k_m.gguf`;
- `Llama-3.2-3B-Instruct-Q4_K_M.gguf`.

Модели не включены в Git. По умолчанию используется CPU. Для сборки
`llama-cpp-python` с поддержкой GPU можно добавить `--gpu-layers -1`.

## ДЗ 1

```powershell
.\.venv\Scripts\python.exe -X utf8 assistant.py
```

Выберите модель в меню или укажите `--model qwen2.5-3b`.
Один запрос: `--message "Найди книгу The Hobbit"`.
Для сравнения моделей: `--model all --message "Какой курс доллара?"`.

## ДЗ 1 + ДЗ 2

```powershell
.\.venv\Scripts\python.exe -m pip install -r homework_2/requirements.txt
.\.venv\Scripts\python.exe -X utf8 assistant_with_memory.py
```

Версия с памятью повторно использует инструменты первой версии. Сообщите своё имя,
город, стек или цели — факты сохранятся в `agent_memory.json`. После перезапуска
можно спросить «Как меня зовут?» или «Какая погода в моём городе?».
`--memory путь.json` выбирает файл, `--user имя` — отдельный профиль.
В памяти хранятся факты, а не переписка. Предложения с вопросительным знаком
не записываются как факты; отделяйте факт от вопроса точкой.

Notebook для сдачи с демонстрацией двух процессов и отдельной CELL диагностики:
[homework_2.ipynb](homework_2/homework_2.ipynb). Подробности: [ДЗ 2](homework_2/README.md).

## Инструменты и команды

| Запрос | Источник |
| --- | --- |
| «Погода в Москве» | [wttr.in](https://github.com/chubin/wttr.in), короткий текст `format=3` |
| «Курс доллара» | [ЦБ РФ](https://www.cbr.ru/development/SXML/), дата курса и номинал валюты |
| «Найди Python в Википедии» | [Wikipedia API](https://www.mediawiki.org/wiki/API:Search), до трёх статей |
| «Найди книгу The Hobbit» | [Open Library](https://openlibrary.org/dev/docs/api/search), до трёх книг |

Для API нужен интернет. При ошибке сервиса программа сообщает об ошибке.
Курс ЦБ пересчитывается за одну единицу валюты. Книги возвращаются как сведения
об изданиях со ссылками; наличие полного текста не гарантируется.
Итоговый текст и извлечение фактов зависят от качества небольшой локальной модели.

`/clear` начинает новый диалог. В ДЗ 2 факты при этом сохраняются; `/memory`
показывает профиль. `пока`, `выход` и `exit` завершают чат.
Короткие благодарности не запускают повторный поиск.
`--debug` включает служебный вывод; в ДЗ 2 он направлен в stderr.
Логи сохраняются в `logs/`. По умолчанию показывается только итоговый ответ.

## Проверка

Все четыре API без загрузки модели:

```powershell
.\.venv\Scripts\python.exe -X utf8 assistant.py --check-apis
```

Отчёт: `logs/public_apis_check.json`. Код выхода `0` — все запросы успешны.
Автоматические проверки без сети и загрузки моделей:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Личная память, `.env`, окружение, модели, логи, кеши и локальные материалы
занятий `context/` исключены из Git. В `homework_2/memory.json` оставлен только
вымышленный профиль демонстрации.
