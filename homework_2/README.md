# Домашнее задание 2 — продолжение ДЗ 1

В проекте два файла запуска:

- `assistant.py` в корне — ДЗ 1: погода, ЦБ РФ, Wikipedia и Open Library.
- `assistant_with_memory.py` в корне — ДЗ 1 + ДЗ 2: те же API, LangChain и память фактов.

Вторая версия повторно использует инструменты и ручной разбор вызовов из первой.
Основной ассистент не превращается в собеседователя или анкету.

## Запуск

Из корня проекта в подготовленном окружении:

```powershell
.\.venv\Scripts\python.exe -X utf8 assistant_with_memory.py
```

Для другого окружения: `python -m pip install -r homework_2/requirements.txt`,
затем `python -X utf8 assistant_with_memory.py`. Флаг `--model llama-3.2-3b`
выбирает вторую локальную модель; по умолчанию используется Qwen на CPU.
Для API нужен интернет, ключи и регистрация не нужны.

## Что добавлено к ДЗ 1

`AssistantWithMemory.chain` — LCEL-конвейер из двух шагов:

1. Отдельный вызов LLM извлекает явно сообщённые факты в JSON. JSON Schema
   ограничивает генерацию, `PydanticOutputParser` проверяет результат, а
   `FileFactMemory` обновляет файл.
2. Ассистент из ДЗ 1 получает актуальный профиль в системном промпте и отвечает
   с доступом к тем же API. Например, город для погоды может взять из памяти.

Сохраняются имя, стек, уровень, цели, предпочтения и город. В файле нет истории
сообщений или ответов API. Исправление заменяет прежнее значение, повтор не
дублируется, `null` не стирает известный факт. Запись атомарная; одновременно
с одним файлом должен работать один чат. При ошибке извлечения профиль не меняется.
Извлечение смысла зависит от качества LLM; проверка JSON проверяет структуру.

По умолчанию рабочая память — `agent_memory.json` в корне, профиль — `student`.
Файл создаётся при первом сохранении факта и исключён из Git.
Флаг `--memory путь.json` выбирает файл, `--user имя` — отдельный профиль.
`/clear` очищает короткую историю, сохраняя факты, `/memory` показывает профиль.
Выход: `пока`, `выход`, `exit`. Благодарности не вызывают повторный поиск.
Факт и вопрос лучше разделять точкой: предложения с `?` не записываются как факты.

## Проверка перезапуска

Сначала:

```powershell
.\.venv\Scripts\python.exe -X utf8 assistant_with_memory.py --user demo --message "Меня зовут Анна. Я живу в Казани. Я пишу на Python."
```

Процесс завершится. Новый процесс:

```powershell
.\.venv\Scripts\python.exe -X utf8 assistant_with_memory.py --user demo --message "Как меня зовут, где я живу и на чём пишу?"
```

Для демонстрационных сведений используйте отдельный `--user demo`.
Диагностика в CLI записывается в лог; `--debug` дополнительно выводит её в stderr.

## Notebook и сдача

Откройте `homework_2.ipynb`, выберите Python из `.venv`, выполните ячейки по порядку.
В notebook отдельная **CELL: память и диагностика**; основной чат показывает только
реплики пользователя и ассистента. Демонстрация запускает второй файл ассистента
в двух отдельных процессах и сохраняет факты вымышленной Анны в `memory.json`
рядом с notebook. Рабочий профиль `student` в корне не меняется.

Сдать notebook с результатами, демонстрационный `memory.json`, оба файла запуска
и общие модули `public_api_tools.py` и `homework_2/chat_memory.py`.
В `chat_memory.py` находятся схема фактов, файловая память и адаптер локальной модели.
